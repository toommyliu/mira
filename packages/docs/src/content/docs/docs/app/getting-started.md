Mira is an automation client for AdventureQuest Worlds on Apple silicon Macs.

## Install

Mira requires macOS 26 or later.

1. Download `Mira.dmg` from the [latest release](https://github.com/toommyliu/mira/releases/latest).
2. Drag Mira to **Applications**, then open it. macOS blocks the first launch because releases are not notarized.
3. Open **System Settings**, then **Privacy & Security**, and select **Open Anyway**.

Mira can update itself after the first launch. Your Mira files live in `~/Mira`.

## Windows

Instead of one window per client, Mira puts every client in a tab, and most tool windows follow the selected tab.

- **Scripts**: Browse scripts and packages, and run scripts. See [writing scripts](/docs/scripting/writing-scripts/basics/).
- **Manager**: Save accounts and setups.
- **Combat profiles**: Save [skill rotations](/docs/app/combat-profiles/).
- **Environment**: Set up drop pickup, quest turn-ins, and boosts for a tab.
- **Packets**: Inspect and send packets between the client and server.
- **Loader/grabber**: Load shops and quests and inspect game data.
