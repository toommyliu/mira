---
title: Mira scripting
---

A Mira script is a generator function. Each `yield*` waits for one call from `mira` to finish.

```ts
import { Combat, Player, Script } from "mira";

export default function* () {
  if (!(yield* Player.isReady())) return;
  while (true) {
    const prey = yield* Combat.hunt("Frogzard");
    if (prey === null) {
      yield* Script.sleep("2 seconds");
      continue;
    }
    yield* Combat.kill({ monMapId: prey.monMapId });
  }
}
```

The API reference lists every export of `mira`, `mira/http`, and `mira/schema`.
